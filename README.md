# ResearchMate: ReAct From Scratch

A learning project using Python, two safe tools, and Groq's OpenAI-compatible API.

## Run
Create a Python 3.11+ environment, install `requirements.txt`, copy `.env.example` to `.env`, insert your own API key, then run `python main.py`.

## Tests
Run `python -m pytest -q`.

All sample documents are fictional. Never commit `.env`.
